# Política de segurança

## Versões com suporte

O Megila ainda não publicou uma versão. Até o primeiro lançamento, as
correções de segurança são aplicadas na branch `main`.

| Versão | Suporte |
| --- | --- |
| `main` | Sim |

## Como reportar uma vulnerabilidade

Reporte vulnerabilidades em privado. Não descreva o problema em issue,
pull request, discussão ou commit público.

O canal é o reporte privado dos
[GitHub Security Advisories](https://github.com/scalet/megila/security/advisories/new)
deste repositório. O relato fica visível só para quem mantém o projeto.
O passo a passo do GitHub está em
[Reportar uma vulnerabilidade de forma privada](https://docs.github.com/pt/code-security/how-tos/report-and-fix-vulnerabilities/report-privately).

Se o formulário não estiver disponível, avise o responsável pelo
repositório, [@scalet](https://github.com/scalet), pelo GitHub, sem
detalhes exploráveis em canal público. Não há endereço de e-mail
público para este fim.

Quando possível, inclua:

- descrição do problema e o impacto;
- versão, commit ou branch afetados;
- passos mínimos para reproduzir.

## Prazo de resposta

Confirmamos o recebimento em até 3 dias úteis. Em até 7 dias úteis após
a confirmação, enviamos uma avaliação inicial: aceite, pedido de mais
informação ou recusa com o motivo.

Se o relato for aceito, a correção e a divulgação são combinadas antes
de qualquer detalhe público. Pedimos que o problema não seja divulgado
até existir uma correção ou um acordo de divulgação.
